# Repository Instructions

This repository is a daily creative-coding sketch archive.

## README Maintenance

Whenever you create or update a `Day_NNN` creative work, update `README.md` in the same change.

The README update must include:

- A new or updated entry in the complete sketch index.
- The sketch title or short description.
- Key techniques or learning points.
- A preview image or GIF link when the day folder contains a suitable visual asset.
- Any run instructions needed for that sketch if they differ from the normal browser/static-file flow.

Before finishing, verify that the README renders well on GitHub:

- Relative image paths should point to files committed in the repo.
- The latest day should be easy to find from the top of the README.
- Keep entries concise and scannable.

## Day Folder Conventions

- Use `Day_NNN` naming with zero padding.
- Prefer `index.html`, `style.css`, `sketch.js`, `Article.md`, and a preview image named `Day_NNN.png` or `Day_NNN.gif` for p5.js sketches.
- Keep sketches self-contained unless a local asset is necessary.
- For browser-based sketches, include enough information for someone to run the sketch locally.
