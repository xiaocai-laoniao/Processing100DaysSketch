# Day_068 音符水母群 / 星图神经元 / 谱面风暴 / 节拍建筑

## 创意

把多段原创 MIDI-like 乐句拆成四个可切换的视觉世界：

- `音符水母群`：每个音符孵化一只带有触须的发光水母，音高决定水层高度，力度决定伞面大小，鼓点把整片海域推出涟漪。
- `星图神经元`：每个音符触发一个神经节点，旋律点亮纤维路径，和弦瞬间连成星座，鼓点沿着时间环打出冲击波。
- `谱面风暴`：音符被卷入一张旋转谱面，旋律变成闪电链路，和弦形成涡旋，鼓点把整张谱面推成风暴眼。
- `节拍建筑`：节拍是地基，低音是承重柱，和弦铺成桥梁，旋律点亮建筑信号灯，把音乐结构建成一座短暂城市。

这版没有使用外部音乐资源，而是在 `sketch.js` 中生成三套原创 score：`潮汐` 偏流动和弦，`星群` 偏高频琶音，`脉冲` 偏低频节拍。每套都能实时驱动四个视觉模式，也能单独导出为标准 MIDI 文件。

视觉逻辑拆成独立文件：`jellyfish-scene.js` 负责水母群，`neural-scene.js` 负责星图神经元，`score-storm-scene.js` 负责谱面风暴，`beat-architecture-scene.js` 负责节拍建筑，`sketch.js` 只保留 score、音频、导出、场景切换和共享工具函数。这样后续继续增加“音画联觉”模式或新的 MIDI 预设时，不需要挤在同一个大文件里。

## 关键知识点

- p5.js 2.3.0 CDN
- MIDI-like note event 生成
- 多 score 预设切换：潮汐 / 星群 / 脉冲
- Web Audio API 合成器
- HTML 场景切换按钮
- 独立 scene JS 文件拆分
- 音符水母群：音高水层、节拍涟漪、触须粒子
- 谱面风暴：旋转谱线、音符闪电、和弦涡旋
- 节拍建筑：节拍地基、低音柱体、和弦桥梁
- 拍位 / 音高 / 和弦分层映射
- 时间环与轨道式音高布局
- 贝塞尔神经纤维与信号粒子
- 和弦 Bloom 多边形
- `createGraphics()` 残影层
- 浏览器内导出标准 MIDI 文件

## 操作

- `水母群` / `1`：切换到音符水母群
- `神经元` / `2`：切换到星图神经元
- `谱面风暴` / `3`：切换到谱面风暴
- `节拍建筑` / `4`：切换到节拍建筑
- `潮汐` / `Q`：切换到流动和弦型 score
- `星群` / `W`：切换到高频琶音型 score
- `脉冲` / `E`：切换到低频节拍型 score
- `Play` / 空格：播放或暂停原创合成乐句
- `Restart` / `R`：重启乐句时间轴
- `MIDI` / `M`：导出当前 score，例如 `Day_068_tidal_synesthetic_score.mid`
- `PNG` / `S`：保存当前画面
